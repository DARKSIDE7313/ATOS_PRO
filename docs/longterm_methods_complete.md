### 方法 1：巴菲特式护城河价值投资

**创始人：** Warren Buffett + Charlie Munger
**来源：** 伯克希尔·哈撒韦 60 年业绩 | 巴菲特致股东的信

#### 核心逻辑
以合理价格买入具有"持久竞争优势"（护城河）的优质公司，长期持有。
巴菲特说："用合理的价格买入优秀的公司，远好于用优秀的价格买入平庸的公司。"

#### 选股标准（5 项硬指标 + 3 项软指标）

**硬指标：**

| 指标 | 巴菲特标准 | 说明 |
|------|-----------|------|
| ROE（净资产收益率） | 连续 10 年 > 15% | 公司用股东的钱赚钱的能力 |
| 毛利率 | > 40% | 有定价权的表现 |
| 经营利润率 | > 15% | 运营效率 |
| 负债/权益比 | < 0.5（或长期负债 < 5年净利润） | 财务稳健，不靠借钱 |
| 每股收益（EPS） | 连续 10 年增长 | 盈利持续增长 |

**软指标（护城河类型）：**

| 护城河类型 | 判断方法 | 例子 |
|-----------|---------|------|
| 品牌护城河 | 消费者愿意多付钱买 | 可口可乐、LV、茅台 |
| 转换成本 | 客户很难换供应商 | Adobe、微软、Salesforce |
| 网络效应 | 用户越多越值钱 | 谷歌、Meta、腾讯 |
| 成本优势 | 成本结构远低于同行 | 好市多、沃尔玛 |
| 规模经济 | 越大越好、越难追赶 | 台积电、亚马逊 |

#### 买入规则
1. 满足 5 项硬指标中至少 4 项
2. 有至少 2 种护城河
3. PE < 15（或 P/E 低于 5 年均值）
4. 市值 > 500 亿美元（只做大盘股，降低风险）
5. 分 3-5 批建仓，每跌 5% 加一批

#### 卖出规则
1. PE > 30 → 减仓 50%
2. 基本面恶化（ROE 连续 2 年下降）
3. 护城河被打破（新技术的颠覆）
4. 找到更好的机会（换仓）

#### 仓位管理
- 单只股票：5-15%（巴菲特最集中时前 5 只占 80%）
- 现金：20-40%（等待危机抄底）
- 组合：8-12 只股票

#### 历史表现
- 巴菲特 1965-2024：年化 19.8%（伯克希尔账面价值）
- 标普500同期：年化 9.9%
- 最大回撤：50%（2008年、2020年3月）

#### 优势
✅ 60 年实战验证，长期有效
✅ 选出真正优质的公司，下行保护强
✅ 不需要频繁操作，换手率极低
✅ 复利效果惊人（20%年化 × 60年 = 5万倍）
✅ 黑天鹅中优质公司往往能反弹

#### 劣势
❌ 需要极强的财务分析能力
❌ 短期可能深度回撤（50%不罕见）
❌ A股/港股符合标准的公司很少（美股多）
❌ 牛市末期跑输市场（1999年和2020年）
❌ 建仓时机不对会套好几年
❌ 不适合自动化实现（软指标需要人判断）

### 方法 2：本杰明·格雷厄姆净净值法 (Graham Net-Net)

**创始人：** Benjamin Graham
**来源：** 《证券分析》(1934) | 《聪明的投资者》(1949)

#### 核心逻辑
买入价格低于公司"净流动资产价值"（流动资产 - 总负债）的股票。安全边际最深的价值投资方法。

#### 选股标准
```
 股价 < 净流动资产价值（Net Current Asset Value）
 净流动资产价值 = 流动资产 - 总负债 - 优先股

 更保守的版本：股价 < 2/3 × 净流动资产价值
```

具体指标：
1. **NCAV/Price > 1.0** — 股价低于净流动资产
2. **流动比率 > 2.0** — 资产健康
3. **负债率 < 0.5** — 不能有太多债
4. **股价/账面价值 < 0.67** — 破净
5. **市值 > 1000 万美元** — 太小不可靠

#### 买入规则
- 任何满足以上标准的股票都可以买
- 分散买入 20-30 只
- 等权重分配

#### 卖出规则
- 股价上涨 50% → 卖出
- 持有超过 2 年 → 卖出（换新的）
- 基本面变差 → 卖出止损（跌 20%）

#### 历史表现
- Graham 1926-1956：年化 17%（实际业绩）
- 学术界回测 1970-2000：年化 10-15%（但股票越来越少）
- Oppenheimer 回测 1990-2008：年化 24%（但样本很少）

#### 优势
✅ 极其安全（买入的是现金价值，而不是"故事"）
✅ 规则清晰，完全可量化
✅ 几乎不可能亏钱（只要有耐心）

#### 劣势
❌ 美股现在几乎没有 Net-Net 了（信息太透明）
❌ 只有极度熊市底部才会出现
❌ 适合小盘股，流动性差
❌ 需要极强的耐心（有时等 3-5 年才回归）

### 方法 3：格林布拉特神奇公式 (Magic Formula)

**创始人：** Joel Greenblatt
**来源：** 《The Little Book That Beats the Market》(2005)

#### 核心逻辑
按两个维度对所有股票排名——便宜度（Earnings Yield）和质量（Return on Capital），选综合排名最高的 20-30 只。

#### 两个核心指标

**指标 1：Earnings Yield（盈利收益率）**
```
Earnings Yield = EBIT / Enterprise Value
= 息税前利润 / 企业价值
```
越高越好（越便宜）

**指标 2：Return on Capital（资本回报率）**
```
ROC = EBIT / (净固定资产 + 净营运资本)
= 息税前利润 / 投入资本
```
越高越好（质量越高）

#### 完整排名流程

```
Step 1: 排除金融股、公用事业、ADR
Step 2: 排除市值 < 5000万的公司
Step 3: 对剩余所有股票分别按 Earnings Yield 和 ROC 排名
Step 4: 两个排名相加 → 总分越低越好
Step 5: 选总分最低的 20-30 只
Step 6: 等权重买入
Step 7: 持有一年 → 换仓（滚动更新）
```

#### 买入规则
- 每月或每季度重新排名一次
- 新选入的股票等权重替换

#### 卖出规则
- 持有一年自动卖出（不管涨跌）
- 如果某只仍然在排名中，继续持有

#### 历史表现
- Greenblatt 回测 1985-2005：年化 30%（标普同期 12%）
- 独立机构回测：年化 15-20%（扣费后）
- 最大回撤：30-40%
- 某些年份跑输（如 1999年科技泡沫）

#### 优势
✅ 完全可量化、可自动化
✅ 不需要主观判断
✅ 同时考虑了便宜度和质量
✅ 分散化，风险低
✅ 回测表现优秀

#### 劣势
❌ 某些年份大幅跑输（尤其是科技牛市中）
❌ 需要处理大量财务数据（yfinance数据质量会影响）
❌ 小市值公司在美股数据不全
❌ 换仓时可能有大量的交易费用
❌ Greenblatt 本人的对冲基金后来表现一般

### 方法 4：Howard Marks 反周期价值投资

**创始人：** Howard Marks
**来源：** 《投资最重要的事》| 橡树资本投资备忘录

#### 核心逻辑
市场情绪像钟摆一样在极度乐观和极度悲观之间摆动。在最大悲观时买入，在最大乐观时卖出。
"最高质量的策略，是在别人恐惧时贪婪，在别人贪婪时恐惧。"

#### 完整框架

**Phase 1：判断市场温度（7 个指标）**

| 指标 | 极度悲观信号（买入） | 极度乐观信号（卖出） |
|------|-------------------|-------------------|
| 标普500 PE | < 10 倍 | > 30 倍 |
| 巴菲特指标（总市值/GDP） | < 60% | > 130% |
| 国债收益率曲线 | 极度倒挂 | 极度陡峭 |
| 信用利差（高收益债券） | > 8% | < 3% |
| VIX 恐慌指数 | > 40 | < 12 |
| 投资者情绪 | 90%+ 看空 | 90%+ 看多 |
| 新股IPO数量 | 几乎暂停 | 疯狂上市 |

**Phase 2：按周期阶段配置**

| 周期阶段 | 股票 | 债券 | 现金 |
|---------|------|------|------|
| 极度悲观（买入区） | 70% | 10% | 20% |
| 恢复期 | 65% | 15% | 20% |
| 乐观期 | 50% | 30% | 20% |
| 极度乐观（卖出区） | 30% | 40% | 30% |

**Phase 3：选股标准（周期底部）**

在周期底部，优先买：
1. 高质量公司（有护城河的）
2. 严重低估（P/E < 10）
3. 资产负债表极度健康（净现金公司）
4. 不受欢迎的行业（大家都不要）

#### 历史表现
- 橡树资本 1995-2024：年化约 14%（不良债权策略）
- 在 2000年、2008年、2020年 3月都有超额收益
- 最大回撤：约 20%

#### 优势
✅ 能在大危机中保护资本
✅ 在别人恐慌时有现金抄底
✅ 避免了"追高"的致命错误
✅ 适合大资金

#### 劣势
❌ 判断"现在在周期什么位置"极难
❌ 过早抄底可能被套 30-50%
❌ 牛市中会跑输（现金太多）
❌ 需要很强的宏观分析能力
❌ 操作频率太低（可能一年只动一两次）

#### ATOS 实现建议

```python

# 每周计算一次 7 个指标
# 根据综合分数调整长线仓位配比
# 极度悲观时：从长线池中加大买入力度
# 极度乐观时：减仓到最低
```

### 方法 5：Michael Burry 深度价值 (Deep Value)

**创始人：** Michael Burry
**来源：** Scion Capital（2008年做空次贷一战成名）

#### 核心逻辑
找到被市场完全抛弃、极度低估的公司，计算其内在价值，在安全边际足够大时买入。
Burry 风格比格雷厄姆更激进——他愿意买在下跌趋势中，只要价格足够便宜。

#### 选股标准（Burry 评分体系）

| 模块 | 指标 | 分数 |
|------|------|------|
| **便宜度** | P/E < 10 | 20分 |
| | P/B < 0.8 | 20分 |
| | P/FCF < 10 | 20分 |
| | EV/EBITDA < 8 | 20分 |
| **财务安全** | 流动比率 > 1.5 | 10分 |
| | 负债/权益 < 0.5 | 10分 |
| | 利息覆盖 > 5x | 10分 |
| **催化剂** | 内幕交易买入 | 20分 |
| | 做空比例 > 10%（潜在的轧空） | 10分 |
| | 股价 52周新低 | 10分 |
| | 股票回购中 | 10分 |

总分 > 100 → 候选。总分 > 130 → 重仓。

#### 内在价值计算（DCF 简化版）

```python
# Burry 风格 DCF
未来现金流量总和 = 最近一年自由现金流 × 8（保守）
账面资产（Book Value）= 最新季度
内在价值 = max(未来现金流量总和, 账面资产)
安全边际 = (内在价值 - 当前价格) / 当前价格

if 安全边际 > 30% → 买入
if 安全边际 > 50% → 重仓
if 安全边际 < 0% → 不买
```

#### 买入规则
1. 总分 > 100
2. 安全边际 > 30%
3. 分散买入 12-18 只（集中持仓）
4. 分 3 次建仓，每次跌 10% 加一次

#### 卖出规则
1. 股价达到内在价值 → 卖出 50%
2. 股价超过内在价值 20% → 全部卖出
3. 如果继续下跌超过 20%（第一次建仓价为基准）→ 止损
4. 基本面恶化（营收下降 30%+）→ 止损

#### 历史表现
- Scion Capital 2000-2008：年化 66%（含做空次贷的巨额收益）
- 2000-2005（纯多仓）：年化约 15%
- 最大回撤：约 30%

#### 优势
✅ 安全边际最大，下行风险低
✅ 适合熊市和平庸市场
✅ 规则清晰，大部分可量化
✅ 你的 ATOS value_investor.py 已经有 Burry 风格实现！

#### 劣势
❌ 在泡沫市场中完全跑输（1999、2020、2024）
❌ 极端的逆向操作，需要极强的心理素质
❌ 可能买了真正的"价值陷阱"（基本面继续恶化）
❌ 选出的股票可能很小（流动性差）
❌ Burry 自己近年业绩争议很大

### 方法 6：彼得·林奇 GARP（Growth at a Reasonable Price）

**创始人：** Peter Lynch
**来源：** 《战胜华尔街》(One Up On Wall Street) | 麦哲伦基金 13 年业绩

#### 核心逻辑
以合理的价格买入成长性好的公司。介于纯价值（Graham）和纯成长（Fisher）之间。核心指标是 PEG。

#### 选股体系（林奇 6 种类型）

| 类型 | 描述 | 目标收益 | 操作方式 |
|------|------|---------|---------|
| Slow Grower（缓慢增长） | 增长率 2-4% | 股息收益 | 看股息率和派息率 |
| Stalwart（稳健型） | 增长率 10-12% | 2年一倍 | PE × 2 时卖出 |
| Fast Grower（快速增长） | 增长率 20-30% | 5-10倍 | 少量买，分散 |
| Cyclical（周期型） | 随经济周期波动 | 低买高卖 | 库存变化是先行指标 |
| Turnaround（困境反转型） | 从亏损变盈利 | 数倍收益 | 资产负债表最差时买 |
| Asset Play（资产型） | 隐藏资产待发现 | 价值释放 | 看账面价值 |

#### 选股标准（Fast Grower）

```
PEG = P/E ÷ 增长率 < 1.0

具体指标：
1. PEG < 1.0（最重要！）
2. P/E < 40（不能太贵）
3. 营收增长率 > 20%（最近3年）
4. 净利润率 > 5%（赚钱的公司）
5. 资产负债率 < 40%（财务健康）
6. 自由现金流 > 0
7. 最好是没人关注的冷门股
```

#### 买入规则
1. 先确认公司类型
2. 如果是 Fast Grower → PEG < 1.0
3. 如果是 Stalwart → P/E × 增长率 < 2
4. 如果是 Turnaround → 现金 > 负债
5. 分 2 次建仓（先买一半，如果继续跌 10% 再买一半）

#### 卖出规则（林奇最核心的原则）
```
卖出信号：
1. 增长率连续 2 个季度放缓
2. PEG > 2.0
3. P/E > 40（即使增长好也太贵）
4. 机构投资者大量持仓（太热门了）
5. 公司开始做不相关的收购（多元化陷阱）
```

#### 历史表现
- 麦哲伦基金 1977-1990：年化 29%（13年翻 27 倍）
- 同期标普500：年化约 15%
- 最大的回撤：约 35%

#### 优势
✅ 兼顾了成长性和估值，最平衡的方法
✅ 在牛熊市中都表现不错
✅ 选出的股票范围广（很多好公司可以选）
✅ 核心指标 PEG 容易量化

#### 劣势
❌ "增长率"是对未来的预测，不是过去
❌ 容易误判：过去的增长不保证未来
❌ Fast Grower 一旦放缓，跌幅巨大（50-80%）
❌ 需要频繁检查基本面（每个季度）
❌ 在低增长环境中 PEG 选不出股票

#### ATOS 实现

```python
# PEG < 1.0 可以量化为筛选条件
# 增长率用过去 3 年算数平均（保守）
# 每月或每季度扫描一次
# 选出符合标准的加入长线观察池
# 配合技术面择时（MA50 上方买入）
```

### 方法 7：Mohnish Pabrai 克隆法 (Pabrai Cloning)

**创始人：** Mohnish Pabrai
**来源：** 《The Dhandho Investor》(2007)

#### 核心逻辑
直接"克隆"世界上最优秀投资人的持仓。与其自己研究选股，不如抄巴菲特、比尔·阿克曼、塞斯卡拉曼等大师的作业——节省大量研究时间。

#### 完整操作流程

```
Step 1: 追踪 10-15 个顶级投资大师的组合
   追踪工具：SEC 13F 文件（每季度更新）
   需要追踪的大师：
     - 巴菲特（Berkshire Hathaway）
     - 塞斯卡拉曼（Baupost）
     - 比尔·阿克曼（Pershing Square）
     - 霍华德·马克斯（Oaktree）
     - 大卫·泰珀（Appaloosa）
     - 索罗斯（Soros Fund）
     - 丹尼尔·勒布（Third Point）
     - Ken Griffin（Citadel）
     - 中国背景：高瓴资本（Hillhouse）

Step 2: 找出大师们共同持有的股票（"共识股票"）
   如果有 3+ 位大师同时持有 → 重点关注
   如果有 5+ 位大师同时持有 → 重仓考虑

Step 3: 验证一致性
   检查该股票是否：
   - 占大师组合 5%+（说明是真爱，不是随便买）
   - 大师在该季度还增持了（不是减仓）
   - 价格比大师买入价高不多（别给大师抬轿）

Step 4: 执行买入
   每季度 13F 文件发布后（2月/5月/8月/11月）
   5 天内完成调仓
```

#### 买入规则
- 每年只调仓 4 次（13F 季度更新后）
- **共识强度规则：**
  - 5+ 大师共识 → 重仓 10% 上限
  - 3-4 大师共识 → 中等仓位 5%
  - 1-2 大师共识 → 观察仓

- **价格安全规则：**
  - 如果股价比大师买入均价高 < 20% → 直接买
  - 如果股价比大师买入均价高 20-50% → 等回调或减半买
  - 如果股价比大师买入均价高 > 50% → 等

#### 卖出规则
1. 该大师清仓 → 你也要卖
2. 持有超过 1 年 → 减半
3. 自己的基本面判断变差

#### 历史表现
- Pabrai 1999-2024：年化约 18%
- 克隆策略回测（Wharton 研究）：年化 15-22%
- 1998-2016 年回测：13F共识策略年化 16.5%（标普 5.5%）

#### 优势
✅ 节省大量研究时间——大师替你研究了
✅ 多大师共识 = 多角度验证
✅ 规则清晰，容易自动化
✅ 回测表现优秀

#### 劣势
❌ 13F 文件延迟 45 天——可能已经在山顶了
❌ 大师也可能犯错（如巴菲特买了 IBM 亏了）
❌ 大资金进出会影响小盘股价格
❌ 需要付费数据源（SEC EDGAR + 解析）
❌ 只有美股适用（没有 13F 数据）

### 方法 8：CANSLIM（威廉·欧奈尔系统）

**创始人：** William O'Neil
**来源：** 《笑傲股市》（How to Make Money in Stocks）| IBD（Investor's Business Daily）

#### 核心逻辑
结合基本面（盈利增长）和技术面（价格动量），在股票启动主升浪时买入。7 个字母代表 7 个条件。

#### C-A-N-S-L-I-M 七要素详解

**C = Current Earnings（当前盈利）**
```
当季 EPS 同比增长 > 25%（最好 > 50%）
如果当季 EPS 增长 < 20% → 不要在最佳买入名单里
EPS 增长加速度 → 比前几个季度更好，是最强信号！
```

**A = Annual Earnings（年度盈利）**
```
过去 3 年 EPS 年复合增长率 > 25%
每年的 EPS 都要增长（不能有一年下降）
ROE > 17%（非常优秀 > 25%）
稳定且加速的增长
```

**N = New Product/Management/High（新产品/新管理/新高）**
```
公司有新产品、新管理层或新行业趋势
股价要在 52 周新高附近（突破盘整区）
绝对不要在 52 周新低附近买股票
新高不是风险——创新高意味着机构在买入！
```

**S = Supply and Demand（供需关系）**
```
流通股少（小盘股更好）
大量股票回购（减少供应）
管理层大量持股（利益一致）
机构持有比例增加（聪明钱在买）
```

**L = Leader or Laggard（领头羊还是跟风狗）**
```
买行业龙头（Relative Strength > 80, 即跑赢 80%的股票）
绝对不买行业里的老三老四
用 RS（相对强度）指标排名
只买 RS > 80 的股票
```

**I = Institutional Sponsorship（机构支持）**
```
至少有 2-3 家著名机构新买入
机构持有数量在增加
绝对不能有大量机构在卖出
R^2 = 最近季度的机构交易方向
```

**M = Market Direction（市场方向）**
```
这是最重要的一个！
在大盘处于升势时才能买
大盘处于跌势时 • 全部清仓 • 持有现金
大盘判断：每天看标普500和纳指的趋势
用大盘指数的 MA50/MA200 判断趋势
大盘跌破 MA50 → 减仓，跌破 MA200 → 清仓
```

#### 买入规则（杯柄形态突破）

```
〖杯柄形态〗
1. 杯底：至少 7 周以上的盘整（缩量）
2. 杯底深度：不深于 30%（正常 15-25%）
3. 杯柄：2-3 周的窄幅回调（缩量至极低）
4. 突破点（Pivot Point）：杯柄的最高点 + 0.10美元

买入触发：
  当天股价以高于 pivot point 的价格交易
  成交量至少比 50日均量大 50%（最好是 100%+）
  开盘后让股价走 30-60 分钟（低位开盘但强势拉升最好）
  
买入量：
  第一次买入：计划仓位的 50%
  如果突破成功（3天内不跌破突破点）→ 加仓 30%
  如果继续强势 → 加到满仓
  
止损（最严格的规则）：
  突破日的最低价下方 2-3%
  绝对不允许亏损超过 8%（欧奈尔的铁律）
```

#### 卖出规则

```
盈利时卖出（8 条规则）：
1. 盈利 20-25% → 开始卖出（不管多看好）
2. 股价从最高点跌 10% → 卖出
3. 股价距 50日均线太远（超过 30%）→ 卖出
4. 连续 2-3个大涨日（Accumulation Days）→ 卖出
5. 顶部出现大量放量下跌 → 立即卖出
6. 市场转为熊市 → 全部卖出
7. 单日放巨量但价格基本不变 → 卖出
8. 止盈永远不止损重要——锁定利润

止损规则（铁律）：
  任何股票亏损达到 7-8% → 无条件卖出！
  不要等反弹，不要补仓，不要转换
  在 7-8% 止损，在 20-25% 止盈
```

#### 仓位管理（金字塔）

```
牛市：
  Top 位置（最高评分股票）：双倍仓位（12-15%）
  一般位置：正常仓位（5-7%）
  总仓位：80-100%
  现金：0-20%

熊市：
  现金 100%（全部清仓）
  最大回撤通常 < 10%（因为止损很少触发）
```

#### 历史表现
- IBD 读者调查：年化 20-50%（最好的读者）
- 回测 1953-2015（O'Neil 研究所）：年化 22.5%
- 标普500同期：年化 8.2%
- 最大回撤：约 25%（2000 年科技泡沫破裂）

#### 优势
✅ 最系统的成长股投资方法（没有之一）
✅ 止损纪律保护资本
✅ 在大牛市中能赚 100-500%
✅ 完全规则化，适合量化/自动化
✅ 把"趋势是你的朋友"变成可执行的操作

#### 劣势
❌ 在震荡市中频繁止损，回撤大
❌ 小盘股流动性差，大资金无法使用
❌ 只成长不价值——可能买到估值极高的股票
❌ 在下降趋势中完全不能操作（空仓数月）
❌ 杯柄形态需要视觉识别（最难自动化部分）
❌ 需要每日关注市场（否则错过突破点）

#### ATOS 实现

```python
# 最核心的可量化部分：
# 1. C（当期盈利）：EPS 增长率 > 25%
# 2. A（年度盈利）：3年 CAGR > 25%
# 3. L（领头羊）：RS 排名 > 80
# 4. M（市场方向）：标普500 > MA200

# 每日/每周自动扫描：
# - 全市场 EPS 增长率排名
# - 相对强度（RS）排名
# - 接近 52 周新高
# - 成交量放大

# 突破形态检测（更难）：
# - 计算盘整区间（至少 7 周）
# - 检测杯柄形态模式识别
# - 突破时成交量确认
```

### 方法 9：费雪成长投资 (Fisher Growth Investing)

**创始人：** Philip Fisher
**来源：** 《怎样选择成长股》(Common Stocks and Uncommon Profits, 1958)

#### 核心逻辑
找到具有长期增长潜力的公司，买入并长期持有（3-5年甚至更长）。费雪是巴菲特"长持优秀公司"理念的来源之一。

#### 15 点选股标准

**产品/服务（4 条）：**
1. 产品或服务是否有充足的市场潜力（至少 3-5 年增长空间）
2. 公司是否在开发新产品/新市场？
3. 公司研发投入是否高效？
4. 公司的销售团队是否优秀？

**管理（4 条）：**
5. 管理层是否诚实、透明？
6. 管理层是否深入理解业务细节？
7. 公司是否有优秀的成本控制和会计？
8. 高管是否持有大量公司股票？

**财务（3 条）：**
9. 利润率是否高于行业平均水平？
10. 公司是否有持续改善利润率的计划？
11. 公司是否在维护高利润率（不靠降价竞争）？

**人力资源（2 条）：**
12. 公司是否有优秀的人才和培训？
13. 公司是否有良好的劳资关系？

**其他（2 条）：**
14. 公司是否有长远规划？
15. 是否有让投资者放心的企业文化？

#### 买入规则
- 不择时——如果你找到好公司，现在就是最佳买入时机
- 集中持仓——最多买 5-10 只
- 重仓——最好的想法分配 20-30% 资金

#### 卖出规则（费雪认为只有 3 个理由卖）
```
1. 你当初的判断错了（公司没有你想象的那么好）
2. 公司基本面已经根本性恶化
3. 你找到了 5 倍于当前持仓的好机会

特别强调：
  • 绝对不要因为股价上涨而卖（涨10倍是正常的）
  • 绝对不要因为市场下跌而卖（暴跌是买入机会）
  • 绝对不要因为微小的利润波动而卖
```

#### 历史表现
- 费雪自己的基金 1954-1987：年化约 15-20%
- 早年业绩更佳，但缺乏完整记录
- 他的方法影响了巴菲特从 "cigar butt" 转向 "great company"

#### 优势
✅ 找到真正伟大的公司并长期持有
✅ 避免了频繁交易的费用和税
✅ 复利效应最大化
✅ 不需要关注市场短期波动

#### 劣势
❌ **完全无法自动化**（15 条几乎都是定性判断）
❌ 如果选错了公司，损失惨重
❌ 需要频繁与公司管理层沟通（只有大机构才能做到）
❌ 不设止损，下跌 50-90% 也可能（如雅虎）
❌ 需要极强的商业洞察力

#### ATOS 实现建议

```python
# 费雪的方法不适合ATOS完全自动化
# 但可以提取可量化部分：
# 1. 毛利率 > 50% 且逐年上升（有定价权）
# 2. 研发费用率 > 5%（重视创新）
# 3. 管理层持股比例 > 10%（利益一致）
# 4. 营收连续 5 年增长
# 5. 利润率扩大趋势
# 
# 作为"长线核心池"的筛选器之一
# 选出后：人工每季度验证管理质量
```

### 方法 10：ARK 创新投资（Cathie Wood 方法）

**创始人：** Cathie Wood
**来源：** ARK Invest | 专注于颠覆性创新

#### 核心逻辑

```
3. 总可寻址市场（TAM）> $1万亿
4. 公司处于 S 曲线的早期阶段（渗透率 < 10%）
5. 有平台效应/网络效应
6. 管理团队有远见
7. 必须属于五大创新平台之一
```

#### 核心仓位结构（ARKK 公开）

```
主题配比：
  47% — AI & 自动化
  21% — 基因组学
  14% — 金融科技
  12% — 下一代互联网
  6%  — 能源存储

Top 持有特点：
  - 特斯拉（多年重仓）
  - Roku
  - Zoom
  - Coinbase
  - 每次大跌都是买入机会（越跌越买）
```

#### 买入规则
- 越跌越买，认为大跌是打折
- 不看短期估值（PEG > 5 甚至 > 10 也正常）
- 建仓周期：3-6 个月
- 核心仓位不动，围绕核心做波段

#### 卖出规则
1. 公司从 S 曲线早期进入成熟期（渗透率 > 50%）
2. 该创新已经被市场充分接受
3. 失去了颠覆原行业的潜力
4. 管理层变动（创始人离开）

#### 历史表现
- ARKK 2020 年：+152%（绝世好年）
- ARKK 2021-2023：-67%（从高点跌了三分之二）
- 成立以来（2014-2024）：年化约 8%（波动极大）
- 2020 年的高点至今（2024）：-60%

#### 优势
✅ 在创新引爆期能获得极其惊人的收益（如 Tesla 涨 20 倍）
✅ 关注的是"未来 5 年"，不是"下个季度"
✅ 提供了不同于传统投资的视角
✅ 适合年轻投资者（能承受高风险）

❌ 平均持仓估值极度昂贵（P/S > 10 是常态）

❌ 依赖创始人眼光——Cathie 2021 年后业绩极差

### 方法 11：Fama-French 多因子模型

**创始人：** Eugene Fama + Kenneth French
**来源：** 芝加哥大学商学院 | 获诺贝尔经济学奖（2013）

#### 核心逻辑
股票的超额回报可以用 3 个（后来 5 个）因子来系统性地捕获。买入因子敞口就是"系统性地占市场便宜"。

#### 原始三因子（1992）

| 因子 | 名称 | 逻辑 | 操作方式 |
|------|------|------|---------|
| **Market** | 市场风险 | 股票比债券风险高，所以有溢价 | 买入大盘股组合 |
| **SMB** | 小盘股 | 小公司比大公司风险高，溢价 | 买入小盘股，卖出大盘股 |
| **HML** | 价值 | 便宜的股票比贵的股票风险高，溢价 | 买入高账面市值比(cheap)，卖出低(expensive) |

#### 扩展五因子（2015）

| 新增加 | 名称 | 逻辑 |
|-------|------|------|
| **RMW** | 盈利能力 | 高盈利公司比低盈利的公司回报更高 |
| **CMA** | 投资风格 | 保守投资的公司比激进投资的公司回报更高 |

#### 还有一种常用因子（Carhart 1997）

| 因子 | 名称 | 逻辑 |
|------|------|------|
| **MOM** | 动量 | 过去 12 个月涨得好的股票接下来继续涨 |

#### 完整因子组合构建

```python
# 用 ATOS 构建因子组合

# Step 1: 股票池（标普1500 成分股）
# Step 2: 每个月计算每个股票的因子值
#    
#    价值因子（Value）：P/B, P/E, P/CF 排名
#    质量因子（Quality）：ROE, 毛利率, 负债率 排名
#    动量因子（Momentum）：12-1个月收益率排名
#    小盘因子（Size）：市值排名（越小越好）
#    低波因子（Low Vol）：过去12个月波动率排名（越低越好）
#
# Step 3: 综合排名（多因子评分）
#    Score = ValueRank × 0.25 + QualityRank × 0.25
#          + MomentumRank × 0.20 + SizeRank × 0.15
#          + LowVolRank × 0.15
#
# Step 4: 选综合排名前 30 的股票
# Step 5: 等权重买入
# Step 6: 每月再平衡
```

#### 因子表现历史

| 因子 | 美国 1963-2023 年化 | 最差 5 年 |
|------|-------------------|----------|
| 标普500（基准） | 10.2% | -2.3%（2000-2004）|
| 价值因子（HML） | 4.5%（超额） | -8%（科技泡沫期）|
| 小盘因子（SMB） | 2.8%（超额） | -6%（2008后）|
| 动量因子（MOM） | 8.1%（超额） | -15%（2009反弹期）|
| 质量因子（RMW） | 3.7%（超额） | -3%（2020泡沫）|
| 盈利因子（CMA） | 3.1%（超额） | -2%（2017后）|
| 低波因子 | 2.0%（超额） | -4%（2003-2007）|

#### 优势
✅ 诺贝尔奖级别的理论支撑
✅ 完全可量化、可自动化
✅ 分散化，不依赖个股判断
✅ 因子组合可以提供超额收益
✅ 学术研究极为丰富

#### 劣势
❌ 因子在某些环境中长期失效（价值因子 2010-2020 失效 10 年）
❌ 多因子组合之间的协方差难以管理
❌ 需要频繁再平衡（每月）
❌ 交易成本会吃掉一部分收益
❌ 过拟合风险（太多因子反而不好）

#### ATOS 实现

```python
# 你的 engine.py 已经有 Fama-French 实现！
# 可以改进的点：
# 1. 增加月度排名和换仓的定时任务
# 2. 加上动量因子（Carhart）
# 3. 增加综合评分系统
# 4. 多因子组合配上 风险预算（risk parity）
```

### 方法 12：股息增长投资 (Dividend Growth Investing)

**创始人：** 无单一创始人，但典型代表有 John Neff（温莎基金）
**来源：** "Dividend Aristocrats" 概念 | 大量巴菲特的股息相关言论

#### 核心逻辑
买入持续增长股息的优质公司。股息不仅是收入来源，更是公司财务健康的"诚实信号"——只有真正赚钱的公司才付得起不断增长的股息。

#### 股息贵族（Dividend Aristocrats）标准

```python
# S&P 500 Dividend Aristocrats 标准：
标准：
1. 标普500 成分股
2. 连续 25 年增长股息
3. 市值 > 30 亿美元
4. 日均交易量 > 500万美元

# Dividend Kings（更高标准）：
1. 连续 50+ 年增长股息
2. 更严格！
3. 只有 50 多家公司达到
```

#### 选股扩展标准

```
第一层：股息历史
  1. 连续 10+ 年增长股息（至少）
  2. 股息支付率 < 60%（有增长空间）
  3. 股息率 > 标普500均值的 1.5x（当前约 2.5%）

第二层：质量
  4. ROE > 15%
  5. 负债率 < 50%
  6. 自由现金流 / 分红 > 1.5x（分红有保障）
  7. 营收连续 10 年增长

第三层：增长潜力
  8. 股息增长率 > 6%（过去 5 年 CAGR）
  9. EPS 增长率 > 股息增长率
  10. 行业需求稳定（非周期）

第四层：估值
  11. P/E < 20
  12. 股息率 > 5 年均值（说明当前价格便宜）
```

#### 经典组合构建

```python
组合 = {
    "长期核心（50%）": ["JNJ", "KO", "PG", "PEP", "CL"],  # 消费品
    "工业（15%）": ["CAT", "MMM", "HON"],
    "科技（15%）": ["MSFT", "AAPL", "AVGO"],  # 科技也开始分红了
    "金融（10%）": ["JPM", "BAC"],
    "公用事业/REITs（10%）": ["DUK", "O"],
}
```

#### 买入规则
1. 满足全部 12 项标准 → 建观察仓
2. 当股息率高于 5 年均值 → 买入
3. 分批建仓（3 次）：每次跌 5% 加一次

#### 卖出规则
```
1. 公司削减股息 → 立即卖出
2. 股息增长率连续 3 年 < 3% → 卖出
3. 股息支付率 > 80% → 卖出（快撑不住了）
4. 被股息贵族名单除名 → 卖出
5. P/E > 30 → 减仓一半
```

#### 历史表现
- Dividend Aristocrats 指数（NOBL）2005-2024：年化约 10.5%
- 标普500同期：年化约 10.0%
- 但最大回撤：Aristocrats 为 28%，标普为 55%
- 在 2022 年熊市中：Aristocrats 跌 5%，标普跌 18%

#### 优势
✅ 下行保护极强（Aristocrats 回撤是标普的一半）
✅ 稳定的现金流收入
✅ 公司质量最高——能 25 年增长分红本身就说明问题
✅ 非常适合长期持有
✅ 波动是所有策略里最小的

#### 劣势
❌ 在牛市中跑输（如 2020-2021 科技牛）
❌ 选股范围窄（美股只有 65 只 Aristocrats）
❌ 利率上升时股息股会被抛弃（2022年）
❌ 股息要交税
❌ 成长性有限（大部分是成熟公司）

### 方法 13：低波动率异象投资 (Low Volatility Anomaly)

**创始人：** 学术研究先驱：Haugen & Baker (1991), Clarke et al (2006)
**来源：** 低波动率股票长期跑赢高波动率股票——违反了传统金融理论

#### 核心逻辑
学术研究发现：低波动率的股票，长期回报反而高于高波动率的股票。这是因为投资者高估了彩票式股票（高波动），低估了稳定的"闷声发财"股票。

#### 选股标准

```python
# Step 1: 计算波动率
# 过去 12 个月的日收益率标准差
# Beta（相对标普500的市场敏感度）
# 最大回撤（过去 1 年）

# Step 2: 筛选条件
1. 波动率（日回报标准差）< 全市场最低的 20%
2. Beta < 0.8
3. 日内振幅 < 3%（最近 3 个月均值）
4. 市场中性——涨跌都缓慢

# Step 3: 加分项
5. ROE > 12%
6. 毛利率 > 30%
7. 负债率 < 40%
8. 股息率 > 2%
```

#### 经典低波动组合

```
最著名的低波动 ETF：
  USMV (iShares MSCI USA Min Vol Factor)
  SPLV (Invesco S&P 500 Low Volatility)
  
典型持仓：
  JNJ, PG, KO, WMT, MCD, V, ADP
  （几乎就是高质量股票）
```

#### 买入规则
- 每月或每季度重新排名
- 用波动率 + Beta 双重指标
- 买入最低波动率的 50 只股票
- 等权重

#### 卖出规则
- 波动率超过全市场 P50 分位（即变成中高波动）
- 基本面恶化（ROE 大幅下降）
- 每月再平衡时自动换掉

#### 历史表现
- 1963-2023（学术回测）：年化 12.5%（标普 9.5%）
- USMV 2011-2024：年化 9.8%（同期标普 12.2%）——最近表现不如历史
- 最大回撤：在 2020年3月只跌了 22%（标普跌 34%）

#### 优势
✅ 学术理论坚实，违反直觉但有效
✅ 下行保护极强（熊市中跌得少）
✅ 组合非常稳定，换手率低
✅ 完全可量化、可自动化

#### 劣势
❌ 最近 10 年表现平庸（低波因子失效了？）
❌ 牛市中大幅跑输（涨得慢）
❌ 波动率是一个后视镜指标（用过去预测未来）
❌ 利率敏感——低波股偏稳健，利率上升时承压

#### ATOS 实现

```python

# 每月扫描：
# 1. 计算全美股 12 个月波动率
# 2. 选波动率最低的 10% 
# 3. 加上质量筛选（ROE/毛利率/负债率）
# 4. 评分排名
# 5. 买入 Top 30
```

### 方法 14：质量因子投资 (Quality Factor Investing)

**创始人：** 经典因子的一部分，Asness/Frazzini (2014) "Quality Minus Junk"
**来源：** AQR 资本管理量化研究

#### 核心逻辑
买入高盈利、高稳定性、高增长的"高质量"公司，避开低质量的"垃圾"公司。质量因子是 Fama-French 五因子之一（RMW）。

#### 质量评分体系（4 个维度）

```python
def quality_score(info: dict) -> float:
    """
    AQR 风格质量评分，4 个维度各 25 分
    满分 100
    """
    score = 0
    
    # 1. 盈利能力（25分）
    #    重要指标：ROE, ROA, 毛利率, 经营利润率
    roe = info.get('returnOnEquity', 0) or 0
    gross_margin = info.get('grossMargins', 0) or 0
    op_margin = info.get('operatingMargins', 0) or 0
    if roe > 0.20: score += 10
    elif roe > 0.15: score += 7
    elif roe > 0.10: score += 4
    if gross_margin > 0.50: score += 8
    elif gross_margin > 0.35: score += 5
    if op_margin > 0.20: score += 7
    elif op_margin > 0.10: score += 4
    
    # 2. 增长稳定性（25分）
    #    盈利增长平稳，不要大起大落
    #    yfinance 不提供多年的历史数据，用营收趋势替代
    revenue_growth = info.get('revenueGrowth', 0) or 0
    earnings_growth = info.get('earningsGrowth', 0) or 0
    if revenue_growth > 0.15: score += 8
    elif revenue_growth > 0.05: score += 5
    if earnings_growth > 0.15: score += 8
    elif earnings_growth > 0.05: score += 5
    # 稳定性—用低波动近似
    beta = info.get('beta', 1) or 1
    if beta < 0.8: score += 9
    elif beta < 1.0: score += 5
    
    # 3. 财务安全（25分）
    debt_equity = info.get('debtToEquity', 0) or 0
    current_ratio = info.get('currentRatio', 0) or 0
    if debt_equity < 50: score += 12
    elif debt_equity < 100: score += 8
    elif debt_equity < 200: score += 4
    if current_ratio > 2.0: score += 8
    elif current_ratio > 1.2: score += 5
    if info.get('freeCashflow', 0) or 0 > 0: score += 5
    
    # 4. 分红/回购（25分）
    div_yield = info.get('dividendYield', 0) or 0
    buyback = info.get('buybackYield', 0) or 0
    payout = info.get('payoutRatio', 0) or 0
    if div_yield > 0.02: score += 8
    elif div_yield > 0.01: score += 4
    if buyback is not None and buyback > 0: score += 5
    if payout > 0 and payout < 0.6: score += 7  # 分期比率健康
    elif payout > 0 and payout < 0.8: score += 4
    if (div_yield or 0) > 0 and (buyback or 0) > 0: score += 5  # 分红+回购=积极的资本配置
    
    return min(score, 100)
```

#### 买入规则
- 综合评分 > 75 → 强烈买入
- 评分 60-75 → 观察
- 评分 < 60 → 不买

#### 仓位
- 组合持有 20-30 只高质量股票
- 权重按评分分配（评分越高仓位越重）

#### 历史表现
- QMJ（Quality Minus Junk）因子 1957-2023：年化 5.2%（超额）
- 在所有市场环境下都正向
- 在熊市中尤其表现好

#### 优势
✅ 所有环境下都正向的超额收益
✅ 熊市中提供下行保护
✅ 选出的都是你"睡得着觉"的公司
✅ 完全可量化

#### 劣势
❌ 牛市中后期跑输（如 2020 年）
❌ 高质量公司通常不便宜，买入时机很重要
❌ 数据依赖性高（yfinance 数据质量是瓶颈）
❌ 只能做多，不能通过做空利润最大化

#### ATOS 实现

```python

# 这个方法可以作为长线组合的"质量筛选器"
# 每月运行一次评分
```

### 方法 15：Ray Dalio 全天候策略 (All Weather Portfolio)

**创始人：** Ray Dalio（桥水基金）
**来源：** 《原则》| 桥水基金业绩 40+ 年

#### 核心理念
经济有 4 种环境：增长/衰退 × 通胀/通缩。你无法预测下一个是什么环境，所以配置一组在任何环境中都能赚钱的资产组合。

#### 四象限框架

```python
# 经济由 2 个变量驱动力
# 增长（高于/低于预期）× 通胀（高于/低于预期）
# = 4 种环境

# 最美好的资产是在 3 种+ 环境中赚钱的资产！
```

**4 种环境 × 对应最佳资产：**

| 环境 | 股票 | 债券 | 商品 | 通胀保护 | 配置比例 |
|------|------|------|------|---------|---------|
| 增长 ↑ 通胀 ↑ （过热） | ✅ | ❌ | ✅ | ✅ | 25% |
| 增长 ↑ 通胀 ↓ （正常） | ✅ | ✅ | ❌ | ❌ | 25% |
| 增长 ↓ 通胀 ↑ （滞胀） | ❌ | ❌ | ✅ | ✅ | 25% |
| 增长 ↓ 通胀 ↓ （衰退） | ❌ | ✅ | ❌ | ❌ | 25% |

#### 经典全天候配置

```
30% — 标普500 (VOO/SPY)
      → 在增长 > 预期时赚钱
      → 通胀上升时不那么糟

40% — 长期美国国债 (TLT)
      → 在衰退和通缩时跌大利好
      → 通胀上升时跌

15% — 中期国债 (IEF)
      → 更稳定的债券配置
      → 在衰退中提供现金流

7.5% — 黄金 (GLD)
      → 在通胀上升时保值
      → 在滞胀中表现最好

7.5% — 商品 (DBC/PDBC)
      → 在通胀上升 + 增长时赚钱
      → 在衰退中跌
```

#### 简化版（ATOS 可用版）

```python
# 简化成 5 种资产，都用 ETF
# 不需要预测未来 — 赌资产之间的低相关性

简化版配置：
  30%  VOO   (大盘股)
  15%  AVUV  (小盘价值)
  20%  TLT   (长期国债)
  15%  IEF   (中短期国债)
  10%  GLD   (黄金)
  10%  PDBC  (商品)

# 再平衡：每季度一次
# 偏离 > 5% → 调回目标比例
```

#### 买入/卖出规则
- 只有一种操作：**再平衡**
- 每年 1/4/7/10 月第一天检查
- 哪个资产跌得最多 → 买入
- 哪个资产涨得最多 → 卖出
- 回到初始比例

#### 历史表现

```
回测 1972-2024 年：

全天候组合：
  年化：8.6%
  最大回撤：15.2%
  正收益年份比例：82%

同期 60/40 组合（股票60%债券40%）：
  年化：9.2%（略高）
  最大回撤：30.4%（高一倍！）
  正收益年份比例：76%

纯股票100%：
  年化：10.2%（最高）
  最大回撤：55%
  正收益年份比例：67%
```

**关键结论：** 全天候放弃了 1.6% 的年化收益，换取了一半的回撤和更高的正收益概率。

#### 优势
✅ 任何环境都有部分资产在涨
✅ 不用预测市场、不用择时
✅ 最大回撤极低（2020年3月仅跌 12%）
✅ 极度省心（每季度操作一次）
✅ 历史上在所有环境中安然无恙

#### 劣势
❌ 牛市中跑输纯股票（2020-2021年）
❌ 债券在 2022 年加息中暴跌 30%——连累全天候
❌ 需要跨资产配置（中国投资者买美债/商品有限制）
❌ 收益天花板明显（年化 8-9% 是上限）
❌ 达利奥自己近年用的不是这个（更复杂的风险平价）

### 方法 21：指数增强型定投

**创始人：** 改良自成本平均法

#### 核心理念
不在固定时间定投固定金额，而是在市场低估时多投、高估时少投。

#### 实现

```python
def enhanced_dca(snp_pe):
    """
    基于标普 PE 的增强定投倍数
    
    标普 PE < 15（低估）→ 正常定投的 2 倍
    标普 PE 15-20（正常）→ 正常定投
    标普 PE 20-25（偏高）→ 正常定投的 0.5 倍
    标普 PE > 25（高估）→ 只投 1/4，存现金
    标普 PE > 30（泡沫）→ 暂停定投，存现金
    """
    if snp_pe < 15: return 2.0    # 加倍投
    if snp_pe < 20: return 1.0    # 正常
    if snp_pe < 25: return 0.5    # 减半
    if snp_pe < 30: return 0.25   # 四分之一
    return 0.0                     # 暂停
```

### 方法 22：内部人交易追踪

**来源：** SEC 内幕交易数据

#### 核心理念
高管买入自己公司的股票，往往是最强的买入信号。

#### 操作

```python
1. 每周追踪 SEC Form 4 内幕交易数据
2. 筛选标准：
   - 内部人（CEO/CFO/主要股东）
   - 买入金额 > $50万
   - 首次买入（或多年后首次）
   - 占该内部人持仓的比例大
3. 多个内部人同时买入 → 最强信号
4. 买入后持有 6-12 个月
```

### 方法 23：做空比例扎空策略 (Short Squeeze)

**来源：** GameStop 事件 (2021) | 学术研究

#### 条件

```
2. 市值 > $20亿（确保流动性）
3. 有催化剂（盈利超预期、新产品）
4. 内部人买入（信号增强）

```

### 方法 24：回撤买入策略

**核心逻辑**

```
  跌 10% → 投入 20% 现金

  如果 PE > 25 但跌了 10% → 只投一半（可能刚开始跌）
  如果 PE < 15 且跌了 10% → 投双倍
```
